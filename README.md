# Joaquin Miguel T. Quintana — Portfolio

A one-page personal portfolio site (plain HTML + CSS, no build step) for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — styling

## Publish on GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Tip: name the repo `<your-username>.github.io` to get the shorter URL `https://<your-username>.github.io/`.

## Editing
All text lives in `index.html`; colors and fonts are set at the top of `style.css` (`:root`).
